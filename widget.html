Home Screen widget

← Back to the forecast

  1. Install Scriptable from the App Store (free).
  3. Open Scriptable, tap +, paste, then tap the title at the top and name it Snow. Tap Done.
  4. On your Home Screen, long-press an empty spot → Edit → Add Widget → Scriptable. Pick a size and tap Add Widget.
  5. Long-press the new widget → Edit Widget:
    • Script: Snow
    • Parameter: purgatory, wolf-creek, vail, park-city, whistler, or all for every mountain. Blank means Purgatory.
    • Leave When Interacting on Run Script: tapping the widget opens this site.

The widget refreshes about every 30 minutes (iOS decides the exact timing); the forecast behind it updates every 3 hours. Add more widgets with different parameters to track several mountains.
